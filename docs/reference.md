### `strata auth`

### `strata auth login`

`strata auth login [OPTIONS]`

Sign in to Looker with OAuth (PKCE + state) and store the access token locally.

- `--looker-url TEXT` — required — env `LOOKER_URL` — Looker UI host URL
- `--api-url TEXT` — env `LOOKER_API_URL` — Looker API host URL, if it differs from the UI host (token is bound to this host)
- `--client-id / --client-guid TEXT` — default `com.gsanalytics.strata.cli` — client_guid of the OAuth client app registered in Looker
- `--redirect-uri TEXT` — default `http://127.0.0.1:48765/oauth/callback` — Redirect URI registered on the OAuth client app (must match exactly)
- `--token-path TEXT` — default `~/.strata/tokens.json`
- `--no-browser` — flag — Don't open a browser or listen locally; paste the redirect URL on stdin instead
- `--timeout INTEGER` — default `300` — Seconds to wait for the redirect

### `strata bootstrap`

`strata bootstrap [OPTIONS]`

Drop full Strata governance into a repo and prep the environment.

- `--repo TEXT` — default `.` — Target repo path
- `--no-git` — flag — Skip .gitignore update
- `--no-conductor` — flag — Skip conductor/ setup
- `--no-mcp` — flag — Skip .mcp.json / .cursor/mcp.json
- `--force` — flag — Overwrite existing files
- `--yes / -y` — flag — Non-interactive: take flags and defaults, no prompts
- `--bq-project TEXT` — BigQuery project for ~/.strata/config.json
- `--cost-threshold-gb FLOAT` — BQ dry-run cost hard stop in GB for ~/.strata/config.json
- `--set-default-repo / --no-set-default-repo` — flag — Write this repo as repo_path in ~/.strata/config.json (default with --yes: only if no config exists yet)
- `--usage-fixture PATH` — usage_facts.json to wire into .mcp.json as STRATA_USAGE_FIXTURE
- `--schema-fixture PATH` — schema_facts.json to wire into .mcp.json as STRATA_SCHEMA_FIXTURE
- `--dry-run` — flag — Print the plan, write nothing (implies no prompts)
