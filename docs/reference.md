### `strata auth login`

`strata auth login [OPTIONS]`

Sign in to Looker with OAuth (PKCE + state) and store the access token locally.

- `--looker-url TEXT` — required — env `LOOKER_URL` — Looker UI host URL
- `--api-url TEXT` — env `LOOKER_API_URL` — Looker API host URL, if it differs from the UI host (token is bound to this host)
- `--client-id / --client-guid TEXT` — default `com.gsanalytics.strata.cli` — client_guid of the OAuth client app registered in Looker
- `--redirect-uri TEXT` — default `http://127.0.0.1:48765/oauth/callback` — Redirect URI registered on the OAuth client app (must match exactly)
- `--token-path TEXT` — default `~/.strata/tokens.json`
- `--no-browser` — flag — Don't open a browser or listen locally; paste the redirect URL on stdin instead
- `--timeout INTEGER` — default `300` — Seconds to wait for the redirect

### `strata check`

`strata check [OPTIONS]`

Gate a LookML repo in CI: exit 0 pass, 1 gate failed, 2 usage error.

- `--repo TEXT` — env `STRATA_REPO_PATH` — Path to LookML repo (defaults to cwd)
- `--usage-fixture TEXT` — env `STRATA_USAGE_FIXTURE` — Usage facts JSON — explore query counts and PDT build costs.
- `--schema-fixture TEXT` — env `STRATA_SCHEMA_FIXTURE` — Schema facts JSON — warehouse column inventory for drift detection.
- `--fail-on CATEGORIES` — default `none` — Comma-separated finding categories that also fail the gate: dead-code, unused-pdt, zombie-pdt, drift; or all / none. dead-code and the PDT categories need --usage-fixture; drift needs --schema-fixture.
- `--baseline FILE` — Baseline file: known finding ids are ignored, so only NEW findings fail --fail-on.
- `--write-baseline FILE` — Write the current findings' ids to this baseline file (sorted JSON), then gate.
- `--json` — flag — Print {passed, failures, counts, source?} as JSON
